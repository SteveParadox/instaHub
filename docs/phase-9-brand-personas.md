# Phase 9 — Brand profiles and personas
Brand profiles store creative DNA: voice, visual palette, art direction, reusable prompt defaults, and reference asset IDs. Personas add consistent character appearance, role, voice rules and continuity memory.

When a brand profile is supplied to the generation endpoint, the server composes a protected creative-context prefix with the user's prompt. This preserves visual/persona consistency while remaining media-agnostic for future video generation.
